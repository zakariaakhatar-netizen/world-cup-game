# World Cup 22 – Adjective Challenge
Baamboozle-style game: comparatives and superlatives. By Mr. Zakaria Akhatar.

Files: index.html (page), style.css (design), questions.js (question bank), game.js (game logic).

## Publish (GitHub Pages)
1. New public repository `world-cup-game`.
2. Upload the 5 files (index.html at the top level).
3. Settings > Pages > Branch `main` / `(root)` > Save.
4. Link: https://YOUR-USERNAME.github.io/world-cup-game/

## Teacher
- 👨‍🏫 Teacher button: add/remove points, set a score, warning, undo, reset (PIN optional, set on the start screen).
- In every question: ▶ Start, ⏸ Stop, ↺ Reset the timer.
- Add questions: edit the list `A` in questions.js (adjective, comparative, superlative, type, noun1, noun2).
